## Getting started

1. Clone the repository:

   git clone https://github.com/srisanjay18/java-project.git
   cd java-project

2. Build with Maven:

   mvn clean package

   The resulting JAR(s) will be in `target/`.

   Or build with Gradle (if a Gradle build exists):

   ./gradlew build

   The resulting JAR(s) will be in `build/libs/`.

## Run

Run the application (adjust the JAR name to match your project):

   java -jar target/your-app-name.jar

Or run from your IDE (IntelliJ IDEA, Eclipse, VS Code) by running the main class.

## Project structure

## Tests
